Instalação
Cole no Terminal e aperte Enter
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/hannasfranco-source/jarvis/main/instalar.sh)"
Funciona em qualquer Mac (Apple Silicon ou Intel). Abra o Terminal com Cmd + Espaço → digite "Terminal".
Cole no PowerShell e aperte Enter
irm https://raw.githubusercontent.com/hannasfranco-source/jarvis/main/instalar.ps1 | iex
Funciona em Windows 10/11. Abra o PowerShell: Win + X → "Windows PowerShell" (ou pesquise "PowerShell" no menu Iniciar).
Passo a passo
1
Instale o Claude Code
Você precisa do plano Pro ou Max da Anthropic. Baixe em claude.ai/download, instale e faça login.
Dica: O Claude Code é o app de desktop da Anthropic. Ele roda no Terminal e é o "cérebro" dos seus agentes.
2
Abra o Terminal (Mac)(Windows)
Aperte Cmd + Espaço, digite Terminal e aperte Enter. Aperte Win + X e clique em Windows PowerShell. Ou pesquise "PowerShell" no menu Iniciar. É nessa tela preta que tudo acontece.
3
Cole o comando de instalação
Copie o comando laranja lá em cima (botão COPIAR), cole no Terminal com Cmd + V e aperte Enter. O instalador vai:
• Instalar o Node.js (se precisar)
• Criar a pasta ~/jarvis/ com tudo
• Perguntar seu nome
• Configurar o painel para abrir sozinho
4
Abra o Escritório no Chrome
Abra o Google Chrome e acesse localhost:4848. Esse é o painel do Jarvis — ele mostra seus agentes em tempo real.
Importante: Use o Chrome. A voz do Jarvis precisa dele.
5
Ative um agente
No Terminal, rode um desses comandos:
cd ~/jarvis/agentes/nutra && claude
cd ~/jarvis/agentes/lancamentos && claude
O agente aparece no painel e você começa a trabalhar com ele.

Configurar Google Ads
📢 Google Ads API Opcional
Permite que os agentes criem campanhas direto pelo Terminal. Faça quando estiver pronto.
  1. Crie um projeto no Google Cloud
    Acesse console.cloud.google.com, faça login com a mesma conta do Google Ads. Clique em Selecionar projeto → Novo projeto. Dê o nome que quiser (ex: "Jarvis").
  2. Ative a API do Google Ads
    No projeto, vá em APIs e serviços → Biblioteca. Busque "Google Ads API" e clique em Ativar.
  3. Crie credenciais OAuth 2.0
    Vá em APIs e serviços → Credenciais → Criar credenciais → ID do cliente OAuth.
    Tipo: App para computador.
    Anote o Client ID e o Client Secret.
    Tela de consentimento: Se pedir, configure com tipo "Externo", coloque seu e-mail como teste e preencha o nome do app (ex: "Jarvis").
  4. Pegue o Developer Token
    Acesse ads.google.com/aw/apicenter na sua conta MCC. Copie o Developer Token. Se estiver como "Pendente", tudo bem — funciona para a sua conta.
  5. Anote o ID da conta MCC
    No Google Ads, o número no canto superior direito (formato xxx-xxx-xxxx). Tire os traços.
    Exemplo: se é 123-456-7890, anote 1234567890.
  6. Coloque as credenciais no Jarvis
    No Terminal, rode:
    nano ~/jarvis/.google-ads.env
    Preencha com os 4 valores:
    GOOGLE_ADS_CLIENT_ID=seu-client-id.apps.googleusercontent.com GOOGLE_ADS_CLIENT_SECRET=seu-client-secret GOOGLE_ADS_DEVELOPER_TOKEN=seu-developer-token GOOGLE_ADS_LOGIN_CUSTOMER_ID=1234567890
    Salve com Ctrl + O, Enter, depois Ctrl + X para sair.
  7. Autorize o acesso
    Rode no Terminal:
    ~/jarvis/bin/google-ads-autorizar
    Vai abrir o navegador pedindo para autorizar. Faça login e autorize. Pronto!
  8. Teste criando uma campanha
    Peça para o agente de Nutra ou Lançamentos criar uma campanha. Ele monta o JSON e roda:
    ~/jarvis/bin/google-ads criar campanha.json --simular
    O --simular só mostra o que seria criado. Sem ele, cria de verdade — mas sempre pausada.
    Importante: Campanhas são criadas SEMPRE pausadas. Você revisa no Google Ads e ativa quando quiser.
Configurar a voz
🎤 Voz do Jarvis
O Jarvis fala usando o navegador (voz robótica) ou o Fish Audio (voz realista e grátis).
  1. Ative a voz básica
    No painel (localhost:4848), clique em "JARVIS · DESLIGADO" no topo. O Chrome vai pedir permissão para usar o microfone — aceite. Agora diga "Jarvis, bom dia" e ele responde.
  2. Crie conta no Fish Audio (grátis)
    Acesse fish.audio e crie uma conta. Vá em API Keys no seu perfil e crie uma chave.
  3. Configure no Jarvis
    Abra localhost:4848/voz.html no Chrome. Cole a chave da API, escolha "Fish Audio" e clique em Salvar. Teste com o botão "Testar voz".
  4. Voz clonada (opcional)
    No Fish Audio, você pode criar uma voz clonada. Depois de criar, copie o ID da voz e cole no campo "ID da Voz" em localhost:4848/voz.html.
🎵 Música e Spotify
O comando "Bom dia" toca Back in Black no Spotify.
  1. Instale o Spotify (app, não web)
    Baixe o Spotify em spotify.com/download e faça login. Abra pelo menos uma vez.
  2. Use o comando
    Com a voz ativa, diga "Jarvis, bom dia". Ele toca Back in Black (no riff, pulando a intro) e dá o briefing do dia.
Dúvidas comuns
O painel não abre no Chrome?
Rode no Terminal: ~/jarvis/escritorio/server.mjs e veja se aparece algum erro. Se disser "porta em uso", alguma coisa já está na 4848. Feche e tente de novo.
O agente não aparece no painel?
O painel lê as sessões do Claude Code. Abra o agente com cd ~/jarvis/agentes/nutra && claude e aguarde uns 5 segundos — ele aparece.
Google Ads dá erro de autorização?
Rode ~/jarvis/bin/google-ads-autorizar de novo. Se continuar, confira se o Client ID e Secret estão certos em ~/jarvis/.google-ads.env.
O Developer Token está como "Pendente"?
Sem problema. O token pendente funciona para acessar suas próprias contas. Você só precisa de aprovação do Google se quiser acessar contas de terceiros.
A voz não funciona?
A voz só funciona no Google Chrome. Verifique se o Chrome pediu permissão do microfone e se você aceitou. Tente recarregar a página.
Spotify não toca a música?
O Spotify precisa estar instalado como app (não a versão web). Abra o Spotify pelo menos uma vez e faça login antes de usar o "Bom dia".
Como atualizo o Jarvis?
Rode o comando de instalação de novo. Ele sobrescreve os arquivos com a versão mais recente sem perder suas configurações (nome, credenciais).
